# 3D 竹知了

中国传统竹制玩具「竹知了」的仿真网页游戏。一根竹签串起一片薄竹片，搓动竹签让竹片高速旋转，竹片切割空气发出夏天蝉鸣般的「哇呜——」声。

## 运行

ES Module 需要 HTTP 环境，不能直接双击 `index.html`：

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

## 玩法

- **鼠标 / 触摸**：在画面上按住来回搓动，搓得越快转得越快
- **摇一摇**：点底部按钮开启，甩动手机
- **手势控制**：点底部按钮授予摄像头权限，前后移动手掌驱动竹片转速
- **视角**：右键拖动（触屏双指拖动）旋转，滚轮 / 双指捏合缩放

两种挑战模式，成绩存在 localStorage：

| 模式 | 目标 |
| --- | --- |
| 长鸣挑战 | 转速高于 900 RPM 的累计秒数达到 15 秒 |
| 极速挑战 | 峰值转速达到 3,200 RPM |

## 技术

- **渲染**：Three.js 程序化建模，竹纹、竹节、竹片孔洞全部用 Canvas 生成，无外部贴图
- **声音**：Web Audio 实时合成，无任何录音采样。振荡器经 tanh 软削波后送入三条带通（共振峰），叠加大幅气流噪声与每转一次的 AM 调制，对应竹片切割空气的周期性脉冲。频率、响度、共振峰位置随实时转速连续变化
- **物理**：每帧按 `dω/dt = -k₁ω - k₂ω²` 积分，搓动给角速度冲量，松手后受空气阻力自然衰减
- **手势**：MediaPipe HandLandmarker，取掌心位移速度映射为角速度冲量

```
js/
├── main.js     场景、主循环、HUD、挑战逻辑
├── model.js    竹知了建模与残影拖尾
├── audio.js    Web Audio 蝉鸣合成引擎
├── physics.js  旋转物理
├── input.js    鼠标/触摸/键盘/摇一摇输入
└── hands.js    摄像头手势识别
```

## 兼容性

需要支持 WebGL2 与 Web Audio 的现代浏览器。摄像头手势与摇一摇为可选功能，缺失时会提示并降级，不影响主要玩法。
